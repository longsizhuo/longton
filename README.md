# Langton's Ant Playground

[朗顿蚂蚁](https://en.wikipedia.org/wiki/Langton%27s_ant) 的交互式可视化模拟器——支持自定义规则字符串和多只蚂蚁同框对抗。部署在 Cloudflare Workers 上。

## 怎么玩

打开页面后：

- **▶ 播放** 让蚂蚁开始走
- 把"每帧步数"拉到 500–2000 加速
- 经典规则跑到约 10000 步会突然涌现"高速公路"

### 试不同规则字符串

每个字母对应一种"格子颜色"被踩到时蚂蚁要做的动作：

| 字母 | 动作 |
|------|------|
| `L` | 左转 90° |
| `R` | 右转 90° |
| `F` | 不转，直走 |
| `U` | 调头 180° |

每走过一格，那格的颜色循环到下一种。规则越长 → 颜色越多 → 动力学越复杂。

#### 推荐试一下

| 规则 | 效果 |
|------|------|
| `RL` | 经典 Langton — 10000 步进入高速公路 |
| `LLRR` | 完美对称的方形生长 ✨ |
| `LRRRRRLLR` | 有机体般的方形扩张 |
| `RRLL` | 双向高速 |
| `LRRL` | 螺旋 |

### 多蚂蚁混战

点 **+ 随机添加** 投放新蚂蚁，它们共享同一张格子图。看看会发生什么：

- 同一规则的多只蚂蚁会互相打散对方的高速公路
- 偶尔合谋画出意外的对称图案
- 三只以上常常陷入永久混沌

更新机制是**快照同步**：每帧所有蚂蚁先基于"上一帧的格子状态"读快照、各自决策，再统一提交。多只蚂蚁同时踩到同一格不会冲突——它们都基于同样的输入做出同样的决策，写回的颜色值天然相同。

## 架构

```
public/
├── engine.js  — 纯仿真层 (World + Ant，无 DOM 依赖，可单独测试)
├── app.js     — 渲染 + 交互层 (Canvas, 控件绑定)
└── index.html — 标记和样式
```

仿真用 **稀疏分块存储**：每 64×64 格压成一个 `Uint8Array(4096)`，整张地图是 `Map<chunkId, Uint8Array>`。蚂蚁第一次踩到某个区域才会创建那块瓷砖。渲染只遍历"视口相交的瓷砖"——无论世界跑了多大，画一帧的开销恒定。

- `CLOUDFLARE_API_TOKEN`
- `CLOUDFLARE_ACCOUNT_ID`
